# Make It Fest 2026 - Mini Hackathon Preparation

> Repositori persiapan Mini Hackathon Make It Fest 2026

## 📁 Struktur Repositori

```
make-it-fest-2026/
│
├── README.md
│
├── docs/
│   ├── 01-project-ideas/       # Ide-ide proyek per tema
│   ├── 02-project-planning/    # Perencanaan proyek
│   ├── 03-system-design/       # Desain sistem
│   ├── 04-ui-ux/               # UI/UX dan wireframe
│   └── 05-development-guide/   # Panduan pengembangan
│
├── templates/                  # Template dokumen
│
└── resources/                  # Referensi dan materi belajar
```

## 🚀 Cara Penggunaan

1. Lihat ide proyek di `docs/01-project-ideas/` sesuai tema yang diundi
2. Gunakan template di `templates/` untuk dokumentasi
3. Isi dokumen perencanaan di `docs/02-project-planning/`
4. Buat desain sistem di `docs/03-system-design/`
5. Rancang UI/UX di `docs/04-ui-ux/`
6. Ikuti panduan pengembangan di `docs/05-development-guide/`
